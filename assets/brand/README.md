# Crucible brand assets (PROPOSAL, owner signs off)

Hand-written SVG, no raster source, no generated imagery.

- `logo.svg` / `logo-dark.svg`: the mark on a 64x64 grid. A trapezoid crucible
  (top edge 48 wide at y=18, base 31 wide at y=53, rounded base corners),
  a flat melt-surface band inset 6 units from the rim, and a 4.5-radius drop
  of melt below it. Cup is ink (`#1C1917`) or bone (`#F6F1EA`); melt is
  ember (`#B8410A` light, `#FF8A4C` dark). The shapes are only fills, so it holds up at 16 px.
- `wordmark.svg` / `wordmark-dark.svg`: mark plus lowercase "crucible" in a
  system monospace stack (monospace echoes event logs and ids). Text is live
  text, not outlined; convert to paths before print use.
- `social-card.svg`: 1200x630 card.
- `preview.png`: render of the light mark and wordmark (resvg + oxipng).
